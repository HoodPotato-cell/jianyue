# 简阅 · Windows 版

把手机上的简阅原样搬到 Windows：同一套渲染引擎（pdf.js + 自研 OOXML/旧版 Office 解析），
所以 PDF 的矢量清晰度、Word/Excel/PPT 的排版还原、缩放和手势手感都一致。

## 运行

要求：Windows 10/11 x64 + [Node.js](https://nodejs.org/) 18 或更高。

1. 解压到任意目录（不要放在中文路径下的只读盘里）
2. 双击 **start.bat**（或「启动.bat」）
   首次会自动 `npm install`（约 100 MB，只做一次），然后打开窗口
   窗口一闪就消失时：看同目录的 **启动日志.txt**，把内容发我

命令行方式：

```bat
npm install
npm start
```

## 窗口一闪就没了？

1. 确认是解压后的文件夹里运行，不是压缩包预览
2. 看同目录 `启动日志.txt`，最后几行就是原因
3. 没有 Electron 也能先用：双击 **browser.bat**（浏览器模式），功能一样，只是没有拖出到别的窗口

## 打包成 exe

双击 **打包.bat**，产物在 `dist\`：
- `简阅 1.4.0.exe` —— 免安装版，双击即用
- `简阅 Setup 1.4.0.exe` —— 安装版，可选安装目录、建快捷方式

## 拖拽

- **拖出**：在书库列表里按住任意文档，直接拖到资源管理器、微信、Outlook 或其它窗口，
  落地就是真实文件（Electron 原生拖拽，带文件路径，不是链接）
- **拖入**：把文件或整个文件夹拖进窗口 —— 文件夹会加入扫描目录，文件会加入它所在的目录，
  随后自动重新扫描并刷新列表

## 功能对照

| 功能 | Windows 版 |
|---|---|
| 自动收录文档 | 扫描桌面 / 文档 / 下载，深度 10 层；可加任意文件夹 |
| PDF | 矢量重绘、按需分页、适宽 / 捏合缩放（Ctrl+滚轮） |
| Word / Excel / PPT | .docx/.xlsx/.pptx 排版还原，多工作表标签、合并单元格 |
| 旧版格式 | .doc（Word 97）、.xls（BIFF8）、.ppt（PPT97）已支持，还原文字/表格/大纲 |
| Markdown | .md / .markdown：标题、代码块、表格、引用、列表、行内样式 |
| 搜索 | 文件名 + 所在目录 |
| 筛选 | 全部 / PDF / Word / Excel / PPT / MD |
| 书库 | 多选合并、追加、重命名、解散，存在 `%APPDATA%\简阅\store.json` |
| 删除文件 | 列表长按/右键菜单或阅读器右上角 ⋯，二次确认后直接删除 |
| 缩放 | 底部 −/百分比/+、适宽、双击切换、Ctrl+滚轮 |
| 界面动画 | 底部面板从底部升起、点外部反向退出（240ms / 200ms，iOS drawer 曲线） |
| 拖出到其它程序 | ✅ |

## 扫描目录

默认：`桌面`、`文档`、`下载`。
菜单 **文件 → 添加扫描文件夹…**（Ctrl+O）可加任意目录；也可以直接把文件夹拖进窗口。
扫描目录会记住，下次启动继续用。

> 不会去扫整个 C 盘：全盘遍历在机械盘上要几分钟，还会把系统目录里的文档全倒出来。
> 需要哪个盘就加哪个盘。

## 快捷键

| 键 | 作用 |
|---|---|
| Ctrl+O | 添加扫描文件夹 |
| F5 | 重新扫描并刷新 |
| Ctrl+滚轮 | 缩放文档 |
| Esc / 返回 | 关闭面板、退出阅读器 |

## 数据与隐私

- 全部在本机解析，不发网络请求；服务只监听 `127.0.0.1` 的随机端口，并带一次性 token
- 书库与扫描目录：`%APPDATA%\简阅\store.json`
- 删除文件是**真删**，不进回收站，确认框里有提示

## 排错

- **白屏**：菜单 视图 → 开发者工具，看 Console 第一条报错
- **列表是空的**：确认文件夹里有 pdf/doc/docx/xls/xlsx/ppt/pptx；用 F5 重新扫描
- **依赖装不上**：项目自带 `.npmrc` 指向国内镜像；公司网络拦截时，换手机热点再试
- **端口冲突**：不需要管，每次启动用随机端口
